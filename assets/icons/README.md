# Ícones locais

Os desenhos reutilizáveis ficam em `sprite.svg`. O HTML referencia cada símbolo com `<svg><use href="assets/icons/sprite.svg#nome-do-icone"></use></svg>`. Tamanho e cor continuam definidos pelo CSS do componente. Não há carregamento de ícones de uma CDN.

Os cinco SVGs individuais são fundos de campos e da nota de privacidade.

Os símbolos `bell`, `calendar`, `calendar-days`, `chevron-down`, `chevron-right`, `circle-check`, `house`, `log-out`, `moon`, `settings`, `stethoscope` usam os desenhos oficiais do [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons). A licença e os créditos estão em `LICENSE-LUCIDE.txt`. Os demais símbolos preservam os desenhos que já existiam no projeto.
