# Ícones locais

Os desenhos reutilizáveis ficam em `sprite.svg`. O HTML referencia cada símbolo com `<svg><use href="assets/icons/sprite.svg#nome-do-icone"></use></svg>`. Tamanho e cor continuam definidos pelo CSS do componente. Não há carregamento de ícones de uma CDN.

Os seis SVGs individuais são fundos dos campos, dos checks e da nota de privacidade. Usam os desenhos oficiais Lucide `user-round`, `mail`, `hospital`, `phone`, `circle-check` e `shield-check`, baixados e armazenados localmente, com licença em `LICENSE-LUCIDE.txt`.

Os símbolos `bell`, `calendar`, `calendar-days`, `chevron-down`, `chevron-right`, `circle-check`, `house`, `log-out`, `moon`, `settings`, `stethoscope` usam os desenhos oficiais do [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons). A licença e os créditos estão em `LICENSE-LUCIDE.txt`. Os seis ícones das especialidades (`person`, `medical-services`, `ecg-heart`, `location-on`, `lightbulb` e `fastfood`) são os SVGs oficiais [Material Symbols Outlined](https://github.com/google/material-design-icons/tree/master/symbols/web), baixados e incluídos no sprite local. A licença está em `LICENSE-MATERIAL-SYMBOLS.txt`. Os demais símbolos preservam os desenhos que já existiam no projeto.
